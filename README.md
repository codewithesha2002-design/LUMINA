# 🌸 Lumina — Period & Wellness Tracker

A beautifully designed, minimal period tracking app focused on **self-awareness, mood tracking, and gentle wellness guidance**.

Built for modern users who want more than just cycle tracking — Lumina helps you understand your body, your mood, and your daily energy.

---

## ✨ Features

* 🩸 **Period Flow Tracking**
  Log flow intensity: None, Light, Medium, Heavy

* 😊 **Mood Logging**
  Track emotional states like Happy, Moody, Tired, Calm

* 💊 **Symptom Tracking**
  Easily select symptoms like:

  * Cramps
  * Bloating
  * Backache
  * Headache
  * Acne
  * Nausea

* 🌼 **Daily Wellness Guidance**
  Personalized affirmations and gentle suggestions based on your state

* 📅 **Clean Daily Log System**
  Minimal UI to quickly log your day without friction

* 🎨 **Aesthetic UI/UX**
  Soft colors, calming typography, and a distraction-free experience

---

## 🧠 Design Philosophy

Lumina is built around:

* **Calmness over clutter**
* **Self-awareness over data overload**
* **Gentle guidance over strict tracking**

```bash

```

### 2. Install dependencies

```bash

```

